# Live 01 - Creating a BIM-GIS App with Cesium

## Project map
- `src/` - app source, including BIM components, React pages, Firebase, and UI templates.
- `public/` - browser-served models, assets, and runtime resources.
- `resources/` - bundled Cesium and Draco resources.
- `index.html`, `style.css`, `vite.config.ts`, `package.json` - app entry, styles, tooling, and scripts.
- `MASTERCLASS.md` - notes for the added semantic-search and local transcription features.

## Run
From this folder, run `npm install`, then `npm run dev`. Use `npm run build` to build the app.
