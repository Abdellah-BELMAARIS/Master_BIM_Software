## Repository layout

Each numbered folder is a separate learning module; read its `README.md` before running it.

- [`1-Static_website`](./1-Static_website) - HTML, CSS, and JavaScript.
- [`2-Interactive_Website`](./2-Interactive_Website) - TypeScript and Vite.
- [`3-Reactive_Apps`](./3-Reactive_Apps) - React, Three.js, and Firebase.
- [`4-BIM_Apps`](./4-BIM_Apps) - That Open Engine and IFC/Fragments tools.
- [`5-Connecting_Workflows`](./5-Connecting_Workflows) - GIS, cloud functions, integrations, and MCP.
- [`6-AI_BIM_Developers`](./6-AI_BIM_Developers) - BIM authoring and AI-related components.
- [`7-Live-masterclasses`](./7-Live-masterclasses) - recorded-session index and project folders.

Run commands inside the module you want to use. Do not run `npm install` at this repository root.
