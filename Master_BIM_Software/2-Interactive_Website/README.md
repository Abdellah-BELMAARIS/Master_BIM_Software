# 2. Interactive website

## Project map
- `index.html` - application entry page.
- `style.css` - shared page styling.
- `src/index.ts` - TypeScript entry point.
- `src/classes/Project.ts` - project data model.
- `src/classes/ProjectsManager.ts` - project state and operations.
- `assets/` - static images and icons.
- `package.json`, `netlify.toml` - scripts and deployment settings. Vite uses its default configuration.

## Run
From this folder, run `npm install`, then `npm run dev`. Use `npm run build` to create the production build.
